# Prompt file for ALIS software refactoring -- UNIT TESTS

> **Cross-cutting unit-test task.** Add fast, isolated unit tests for the
> *stable surface* of every stage implemented so far (Stages 1-3), wire them into
> a dedicated CI job that runs on every push, and make them trivially runnable
> locally. This is distinct from the Stage 0 regression harness (end-to-end
> golden-file fits): unit tests pin down individual functions and localise
> failures; the regression suite remains the behaviour gate.
>
> **Status: PLAN ONLY -- do not implement until RJC approves.**

## Decisions (confirmed by RJC)

- **I/O scope:** *defer* the file-format loaders (`load_fits` / `load_ascii` /
  `load_data` / heavy `load_model` parsing) to Stage 5, which reshapes I/O.
  Unit-test only the pure/stable logic now.
- **CI matrix:** ubuntu-latest **and** macos-latest, py3.13 (mirrors the existing
  `examples` job).
- **Coverage:** add `pytest-cov`, print a coverage report in CI and locally, but
  **no threshold gate** yet (modules still churn through Stages 4-6).

## Design

- **New `unit` marker** in `pytest.ini` (registered; `--strict-markers` is on).
- **Every unit test is fast and isolated:** no fits, no subprocess, no golden
  files, no network; target < ~1 s each; deterministic (seeded RNG only).
- **Local run:** `pytest -m unit` (whole batch, seconds). Documented in
  `tests/README.md`.
- **CI:** a new `unit` job in `.github/workflows/ci.yml` (ubuntu + macOS, py3.13)
  running `python -m pytest -m unit --cov=alis --cov-report=term-missing`. The
  existing `examples` and `lint` jobs are unchanged. Add `pytest-cov` to the
  `[dev]` extra in `pyproject.toml`.
- **Reuse the existing pattern:** the pure tests already in `test_convergence.py`
  and the `_runs_z` test in `test_fit_report.py` get the `unit` marker; the
  fit-driven integration test in `test_fit_report.py` stays *out* of the unit
  batch (it runs a real fit -> regression territory).
- Every new test file/function carries the "Generated by RJC and Claude"
  docstring line, PEP8 / 88-char.

## Test targets (stable surface, by module)

**Stage 1-2 pure utilities**
- `alis/utils.py` -> `tests/test_utils.py`
  - `numtorn` / `rntonum` (roman <-> ion charge): round-trip identity, the
    `subone` neutral-state toggle, and boundary/error cases (< 1, > 55).
  - `numtoelem` (atomic number -> element): representative Z, the special-case Z
    (36, 42, 54), and out-of-range error path.
  - `getreason` (convergence-reason id -> string): known ids + `verbose` guard.

**Stage 2 configuration**
- `alis/config.py` -> `tests/test_config.py`
  - `_DictLike` behaviour: `__getitem__` / `__setitem__` / `__contains__` /
    `keys` on a representative config.
  - Documented defaults, incl. the Stage 3 changes now baked in:
    `RunConfig.cache is True`, `OutConfig.report is True` / `reportsig == 3.0`,
    `SimConfig.convergetest == "maxdev"` / `convergesig == 3.0`, plus core
    defaults (`blind`, `logn`, `bintype`).
  - `ArgFlag` nested composition (`argflag['run']['cache']` etc.).

**Stage 3.4 -- cache / Jacobian helpers (minimise.py, pure)**
- `alis/minimise.py` -> `tests/test_minimise_helpers.py`
  - `_cache_key_spsn`: both key shapes (`('wave', sp, sn)` and
    `(sp, sn, ea, md, mm)`) map to the correct `(sp, sn)`.
  - `_param_spsn_map`: builds the param -> {(sp,sn)} map from a synthetic
    `_pinfl`; returns `None` on the documented fallbacks (no compcache / no
    `_pinfl`).
  - `_slice_emab`: `None` compcache -> `[None, None, None]`; `None` param_spsn
    -> full-cache passthrough; a real chunk selects exactly the influenced
    sp/sn entries and always drops `modelem`/`modelab`.
  - `enorm`: equals `sqrt(dot(v, v))` on sample vectors.

**Stage 3.3 -- convergence (extend existing)**
- `alis/convergence.py` -> extend `tests/test_convergence.py`
  - Keep/mark the existing `assess_restarts` maxdev/scatter/verdict/fixed-param
    tests as `unit`; add edge cases: all-fixed parameters, a single restart, and
    `convergesig` scaling of the pass/fail boundary.

**Stage 3.2 -- report math (extend existing)**
- `alis/report.py` -> extend `tests/test_fit_report.py`
  - Keep/mark the `_runs_z` unit test as `unit`; add a `_runs_z` degenerate case
    (all-same-sign residuals) and a `_regions` unit test on a synthetic
    wave/mask (correct region boundaries + per-region pixel counts). The
    fit-driven integration test stays as-is (not `unit`).

**Stage 2/3 -- stable load.py logic (non-file-format)**
- `alis/load.py` -> `tests/test_load_units.py`
  - `cpucheck`: ncpu resolution (explicit n, `-1`/all, over-request clamp).
  - `get_binsize`: `km/s` vs `A` vs `Hz`, `maxonly` on/off, edge grids.
  - `getis` / `load_tied`: tied-parameter expression resolution against a
    synthetic influence table (the mechanism links depend on).
  - `load_par_influence`: `_pinfl` structure on a small synthetic model (this is
    exactly the table Stage 3.4 Phase 2 relies on).
  - `load_atomic`: smoke/schema test -- loads `data/atomic.xml`, returns the
    expected structure, and a known transition (e.g. HI Lya) is present with
    sane wavelength/f-value. (Reads shipped data, no external I/O.)

**Stage 2 -- logging (light)**
- `alis/logger.py` -> `tests/test_logger.py`
  - `set_verbosity` + verbosity gating: `info`/`warn` are suppressed below their
    level and emitted at/above it (captured via `caplog`/stub, no real exit).

## Non-goals (explicitly deferred)

- File-format I/O loaders (`load_fits`/`load_ascii`/`load_data`/full
  `load_model`) -> **Stage 5** (I/O refactor), tested there with fixtures.
- GPU / CPU-GPU equivalence -> **Stage 4**.
- `model_eval` cache internals beyond the helpers -> already covered
  bitwise by the `test_cache_equivalence` integration suite.
- End-to-end fit numerics -> the Stage 0 regression harness (golden files).
- No coverage threshold gate yet (report only).
