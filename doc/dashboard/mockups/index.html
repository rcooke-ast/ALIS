ALIS dashboard · Stage 0

Dashboard Mockups

Final (sixth) draft of the static mockups of the ALIS dashboard, closing dashboard Stage 0. Each window is drawn at 1440×900 from real fits: VMP_DLA/J1358p6522, DH/Q1243p307 and, for the Compare sub-tab, DH/J1358p6522. They are pictures of the layout, not working controls.

Changed in draft 6: velocity axes label positive ticks with "+" (0 stays unsigned); every zoom toolbar has "+" and "−" buttons that zoom along the wavelength axis only, and the Compare sub-tab now has the toolbar too.

The run history, progress curve and the moved KIRKMAN file are invented to show those features. Everything else is drawn from the fits and their reference outputs.
